# Zenpyro Call: downloads

Installers for **Zenpyro Call**, the desktop phone for teams on Zenpyro CRM (and anyone with their own Twilio account). This repository only holds releases; the source code is private.

## Download

**[⬇️ Download the latest version for Mac](https://github.com/zenpyrodigital/zenpyro-call-releases/releases/latest/download/Zenpyro-Call-mac-arm64.dmg)** (Apple Silicon, M1 or newer)

Release notes for every version: [Releases](https://github.com/zenpyrodigital/zenpyro-call-releases/releases).

## Install

1. Open the downloaded `.dmg` and drag **Zenpyro Call** into **Applications** (choose **Replace** if you have an older version).
2. First launch only: if macOS says it *could not verify* the app, go to **System Settings → Privacy & Security → Open Anyway**.
3. Sign in:
   - **Your team uses Zenpyro CRM:** Settings → Phone Line → **Sign in with Zenpyro CRM**, and enter your CRM address.
   - **On your own:** click **Connect Now** and paste your Twilio Account SID and Auth Token from [console.twilio.com](https://console.twilio.com).
